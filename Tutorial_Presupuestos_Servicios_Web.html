Módulo: Generador PDF Categoría: Servicios Web Página 1 de 4

Este instructivo detalla el procedimiento para emitir propuestas comerciales en PDF de los productos de la categoría Servicios Web en Odoo. El módulo cuenta con 6 plantillas automatizadas con diseño profesional, listas para enviar de forma inmediata a los clientes.

1 Selección del Producto en Odoo y Plantillas Asociadas

Al crear una orden de venta en Odoo, el sistema detecta de forma automática qué plantilla debe utilizar según el producto cargado en las líneas del pedido:

Producto en Odoo Plantilla HTML Asociada Páginas Alcance
Cloud Server Cloud-Plantilla.html 4 Servidor Cloud
Soporte y Mantenimiento Web Soporte-y-Mantenimiento-Web-Plantilla.html 4 Mantenimiento
Registro o actualización de dominios Gestión-de-Dominio-Plantilla.html 4 Gestión Dominio
Servicio de Hosting Plantilla-Hosting.html 4 Alojamiento Web
Certificado SSL SSL-Plantilla.html 4 Seguridad Web
Servicio Web Completo (Pack) Servicios-Web-_Completo_-Plantilla.html 7 Pack Integral
⚠️
Regla crítica de cotización: Cargar UN solo producto por presupuesto
• Productos individuales: Si cargás varios productos sueltos en las líneas, el sistema usará únicamente la plantilla del primer producto de la lista.
• Cotización integrada: Para cotizar todo junto (Dominio + Hosting + SSL + Mantenimiento) tenés que usar exclusivamente el producto "Servicio Web Completo (Pack)", cargado solo y sin agregar los otros productos en las líneas.
2 Dinámica del Formulario en Servicios Web

El formulario de Odoo adapta su comportamiento para simplificar la carga y evitar confusiones en esta categoría:

🚫 Campos que se ocultan automáticamente

Para todos los productos de Servicios Web, los campos Esp. Técnicas editables y Esp. Técnicas Web se ocultan de la vista y no son obligatorios. No hace falta completarlos.

⚙️ Aparición dinámica de campos técnicos

Los campos específicos (como vCPU y RAM para Cloud, o actualización de contenidos para Soporte) aparecen solos en pantalla según el producto seleccionado en la cotización.

3 Campos Comunes de Cabecera en Odoo

En el formulario de la orden de venta debés completar los campos comerciales compartidos que nutren al PDF:

Campo en Odoo Qué ingresar / Reglas y validaciones Destino en el PDF
Forma de pago Obligatorio en Odoo. Texto libre. No se imprime en estas plantillas (solo es obligatorio en Odoo)
Fecha de expiración Fecha límite de la oferta comercial. Se imprime automáticamente con el formato: "Plazo de validez de la oferta: Hasta el dd-mm-aaaa". La fecha de emisión se autocompleta con el día actual. Página de Condiciones Generales
Condiciones editables. Obligatorio. Texto libre, máx. 315 caracteres. Se corta automáticamente en renglones de ~105 caracteres. Hasta 3 renglones (Cloud y Pack imprimen solo 2). Página de Condiciones Generales
Texto cliente Texto breve en 1 solo renglón, máx. 85 caracteres (Odoo no permite escribir más). Texto personalizado para el cliente. (No aplica al Pack Servicio Web Completo). Página 1 (Portada del PDF)
Aclaraciones Bloque de observaciones comerciales de hasta 340 caracteres. Se corta automáticamente en renglones de ~85 caracteres. NO hace falta separar con punto. (No aplica al Pack). Página 1
Cantidad meses Por defecto "6 meses". Se imprime como "Contratación mínima: X meses" en Hosting, Soporte, SSL y Pack. Cloud trae fijo "12 meses"; Dominio no lo usa. Página de Condiciones Generales
📏 Renglones de "Aclaraciones" por Plantilla
  • Cloud Server: Imprime hasta 4 renglones (~340 car.).
  • Soporte y Mantenimiento Web: Imprime hasta 4 renglones (~340 car.).
  • Gestión de Dominio: Imprime hasta 3 renglones (~255 car.).
  • Servicio de Hosting: Imprime hasta 3 renglones (~255 car.).
  • Certificado SSL: Imprime hasta 3 renglones (~255 car.).
  • Todo texto que exceda esos renglones no se imprimirá en el PDF.
✂️ Corte Automático Inteligente

A diferencia de otros módulos (como Agendas), acá no tenés que poner puntos finales para forzar renglones. El sistema calcula los saltos de línea cada ~85 caracteres respetando palabras completas para que el texto fluya de forma prolija.

💡
Ejemplo para copiar y pegar en "Aclaraciones":
Incluye migración del sitio actual sin costo. Configuración de 5 casillas de correo corporativo. Soporte prioritario durante el primer mes.
(Texto de 144 caracteres que se acomoda automáticamente en 2 renglones limpios en cualquiera de las plantillas).

4 Campos Específicos según el Servicio Cotizado

Al seleccionar ciertos productos, se activan campos particulares que definen las características técnicas del servicio:

☁️ Cloud Server (Página 2 del PDF)

Completás los recursos asignados. Aceptan decimales (ej: 2 se imprime "2", y 0,5 se imprime "0,5"):

Cantidad de vCPU:2 → "2 vCPU's"
RAM (GB):4 → "4 GB RAM"
Storage SSD (GB):50 → "50 GB SSD Storage"
Transferencia (TB):1 → "1 TB de transferencia"
Copia seguridad Std (GB):50 → "50 GB de copia de seguridad Standard"
Conexiones RDP:1 → "1 conexión RDP incluida"
🛠️ Soporte y Mantenimiento Web (Página 2)
• Actualización de contenidos web: Máx. 300 caracteres. Se formatea automáticamente en renglones de ~100 caracteres (hasta 3 renglones) y se imprime debajo de "• Actualización de Contenido web".
• Interruptor "Estadísticas web": Encendido por defecto. Imprime debajo de "• Estadísticas web":
- Sí: "Este presupuesto si incluye este servicio."
- No: "Este presupuesto no incluye este servicio."
Gestión de Dominio, Hosting y SSL: Utilizan únicamente los campos comunes.
Servicio Web Completo (Pack): Solo campos comunes + Cantidad meses (no usa texto cliente ni aclaraciones).
5 Origen de Precios y Esquema Tarifario

Todos los valores monetarios se imprimen en el PDF bajo el formato estándar: $ 9.535 + IVA (redondeados sin decimales, en negrita):

Plantilla / Servicio De dónde sale el precio en Odoo Modalidad
Cloud Server Precio de venta del producto "Cloud Server" en el catálogo. Cuota mensual
Soporte y Mantenimiento Precio de venta del producto "Soporte y Mantenimiento Web" en el catálogo. Tarifa mensual
Gestión de Dominio Precio de venta del producto "Registro o actualización de dominios" en catálogo. Tarifa anual
Certificado SSL Precio de venta del producto "Certificado SSL" en el catálogo. Cuota mensual
Servicio de Hosting Precio unitario de la línea del presupuesto (se puede ajustar en la cotización). Cuota mensual
Servicio Web Completo (Pack) Los 4 precios salen del catálogo de cada producto: Dominio (anual), Hosting (mensual), SSL (mensual) y Soporte como "Actualización Web" (tarifa básica mensual). El precio del producto "Servicio Web Completo" NO se usa. Desglose integral
⚠️
Cómo actualizar precios de catálogo y advertencia sobre nombres:
• Modificar precios fijos: Ir a Ventas > Productos > Productos, abrir el producto deseado y modificar el "Precio de venta".
• ¡NO renombrar los productos!: El sistema busca los productos en la base de datos por su nombre exacto. Si se renombra un producto o no se encuentra, el lugar del precio en el PDF quedará completamente vacío.

7 Anatomía y Páginas del Documento Final
📄 Plantillas Individuales (4 Páginas)

Cloud Server, Soporte Web, Dominio, Hosting y SSL

  • Pág. 1: Portada, cliente, precio, texto cliente y aclaraciones.
  • Pág. 2: Qué incluye el servicio (en Cloud: características técnicas; en Soporte: actualización de contenidos y estadísticas web).
  • Pág. 3: Condiciones generales: contratación mínima, condiciones editables, cuentas bancarias, fecha de emisión y validez.

📑 Servicio Web Completo (7 Páginas)

Solución integral Pack con todos los servicios

  • Pág. 1: Portada con los 4 precios: Dominio (tarifa anual), Hosting, SSL y Actualización Web (cuota/tarifa mensual).
  • Pág. 2 a 5: Qué incluye cada servicio: Gestión de Dominio, Hosting, Certificado SSL y Soporte y Mantenimiento.
  • Pág. 6: Condiciones generales: contratación mínima, condiciones editables (2 renglones), cuentas bancarias, fecha de emisión y validez.
  • Pág. 7: Hoja de aprobación del presupuesto con firma del cliente.
8 Preguntas Frecuentes del Equipo Comercial
💬
"Un renglón de aclaraciones se sale del margen"
Acortá levemente el texto ingresado. El sistema corta a ~85 caracteres, pero si hay palabras muy largas puede desbordar. Si pasa seguido, avisá a sistemas.
💬
"El precio sale completamente vacío"
El producto fue renombrado en catálogo o no existe. Revisá en Ventas > Productos que el nombre coincida exactamente con la denominación oficial.
💬
"Cargué Hosting + SSL y salió solo Hosting"
Cada presupuesto individual toma la plantilla del primer producto. Para cotizar ambos servicios juntos tenés que usar "Servicio Web Completo (Pack)".
💬
"¿El Cloud Server acepta valores como 0,5 TB?"
Sí, todos los campos técnicos de Cloud aceptan valores decimales. Si escribís 0,5 en transferencia, el PDF imprimirá con precisión 0,5 TB.
